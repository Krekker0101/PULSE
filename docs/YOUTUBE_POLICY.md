# YouTube Data API и доступные возможности

Official YouTube Data API v3 documentation:

- https://developers.google.com/youtube/v3/docs/channels/list
- https://developers.google.com/youtube/v3/docs/playlistItems/list
- https://developers.google.com/youtube/v3/docs/videos/list
- https://developers.google.com/youtube/terms/developer-policies

PULSE can discover publicly accessible videos and Shorts *candidates*, read the available source video metadata and follow their YouTube links. The API does **not** provide copies of arbitrary MP4 files, guarantee access to every video, or grant copyright permission to republish someone else's audio/video. This build does not scrape or bypass protected streams.

YouTube-derived custom Viral Score is disabled; metadata is refreshed and stale unauthenticated data is scrubbed after 29 days. Public and historical metrics may be missing or revised. Source title, image and other API data should be refreshed according to the current YouTube API Services Policies.
