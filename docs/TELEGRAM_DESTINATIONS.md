# Telegram: каналы, группы и темы

В личном чате PULSE откройте «Мои аккаунты» → Telegram → «Добавить канал/группу».

Кнопка добавления открывает стандартный Telegram deep link. Для канала предоставьте боту статус администратора с правом публикации сообщений. Для группы достаточно членства с разрешением отправлять сообщения и видео; лишние права PULSE не требует.

После добавления используйте системную кнопку выбора чата. Это единственное исключение из inline-клавиатур: Bot API `request_chat` работает через reply keyboard. Публичный и приватный канал подключаются одинаково, без копирования ID. Выбор привязан к текущему request_id в PostgreSQL FSM. PULSE повторно проверяет владельца/администратора и права бота через getChatMember.

В группе или нужной теме форума отправьте `/pulse_connect` от владельца PULSE. Бот сохранит фактические chat_id и message_thread_id, а карточку направления отправит в личный чат. Подключение само по себе ничего не публикует.

Проверьте направление и включите публикации. В карточке доступны расписание, часовой пояс, дни недели, суточный максимум, интервал, шаблон описания, приоритет, история, пауза и отключение. «Видео / файл» переключает sendVideo/sendDocument для несовместимого формата.

Отправьте боту собственное видео, откройте его источник и подтвердите права. В карточке ролика нажмите «Опубликовать», выберите несколько направлений и подтвердите «сейчас», «по расписанию» или «на подтверждение». У каждого направления своё задание и результат. Повторное подтверждение не создаёт дубликаты.

Перед каждой отправкой проверяются полномочия пользователя и права бота. Отзыв прав переводит направление в NEEDS_ATTENTION и отключает публикации. Удалённая/закрытая тема определяется при отклонении отправки; PULSE не выполняет фиктивную пробную публикацию для проверки темы. Доступного API перечисления всех существующих тем здесь нет; выбор делается командой непосредственно в теме.

Если ответ Telegram потерян, статус — RECONCILIATION_REQUIRED. Проверьте чат вручную: Bot API не даёт идемпотентный ключ sendVideo или универсальное чтение истории для безопасного автоматического повтора. Оригинальное задание автоматически не повторяется. При rate limit ожидание соответствует retry_after. При миграции группы сохраняется новый chat_id.

Источники: [Bot API](https://core.telegram.org/bots/api), [deep links](https://core.telegram.org/bots/features#deep-linking).
